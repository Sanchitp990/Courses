# Some terms you will hear in the world of programming

1. ***Programming languages:*** Programming language is a way to communicate with computers/computer hardware.

2. ***bit & byte:*** A bit is a binary value that can be either 0 or 1 which computers use to process information. And a byte is a collection of 8-bits which computers use.

3. ***Variables:*** In simple words a variable is used to store data in computer momory.

4. ***IDEs:*** In simple trem an IDE or Integrated Development Environment is an software apps that allows developer to write, read and debug code in one place.
