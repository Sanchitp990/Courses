# Chapter - 01 | Get Started

To get started with C we first need to install a compiler and a code editor. This course mainly talks about windows.

## Installation of C Compiler

For Windows, we can use [MinGW (Minimalist GNU for Windows)](https://sourceforge.net/projects/mingw/) as our C compiler.

## Installation of Code Editor

There are many types of code editors like, vs code, dev c++ or others, but in this session we are using [Visual Studio Code](https://code.visualstudio.com/Download).
After installing vs code we need to install an extension for c which is C/C++ extension.
